# LPA 条款图谱

> 面向私募基金入门者及法律从业者的有限合伙协议（LPA）结构化阅读、审阅与起草辅助工具。

## 在线阅读

**GitHub Pages：**  
https://hellyai.github.io/lpa-clause-map/

无需安装，使用电脑或手机浏览器即可访问。

## 项目简介

LPA 通常篇幅较长，条款之间又存在大量交叉关系。只按合同文字顺序阅读，容易看见单个条款，却难以理解基金从设立、募集、投资、管理、分配到退出和清算的完整逻辑。

本项目将 LPA 拆分为 38 个结构化篇章，并按照较完整的协议阅读顺序组织内容。每项条款分别展示：

- 基本规则与知识；
- 审核要点及常见分歧；
- 起草落点；
- 相关法律法规及自律规则依据。

项目希望帮助使用者先理解一项条款解决什么问题，再判断其权利义务、谈判空间和合规边界。

## 主要功能

### 1. LPA 结构化目录

按照基金生命周期和合伙协议常见结构组织篇章，可通过目录直接定位并展开对应内容。

### 2. 条款逐层展开

先阅读篇章概要，再逐条查看基本规则、审核分歧、起草落点和规则依据，降低初次接触 LPA 的阅读门槛。

### 3. 搜索与分类筛选

支持按照关键词搜索管理费、收益分配、后续募集、关键人士、回拨、投资载体等内容，并可按模块筛选篇章。

### 4. 法规交叉检索

条款与相关法律法规、自律规则及合同指引进行交叉对应。法规按钮可跳转至公开权威来源，便于进一步核验原文。

### 5. 个人批注与阅读笔记

使用者可以在具体条款下添加个人批注，并在“我的阅读笔记”中集中回看或导出 Markdown。

批注仅保存在当前浏览器的本地存储中：

- 不会修改原网页；
- 不会被其他读者看到；
- 不会自动上传至 GitHub；
- 不同设备和浏览器之间不会自动同步；
- 清除浏览器网站数据后可能丢失，建议定期导出备份。

## 内容结构

网页内容覆盖 LPA 的主要生命周期模块，包括但不限于：

- 基金设立、基本情况与期限；
- 合伙人、募集、认缴与出资；
- 后续募集与违约处理；
- 管理人、普通合伙人及治理机制；
- 投资范围、投资限制与投资载体；
- 管理费、合伙费用和税务承担；
- 收益分配、业绩报酬与回拨；
- 有限合伙人和普通合伙人的入伙、退伙及权益转让；
- 信息披露、托管、反洗钱及相关运营安排；
- 管理人失能、关键人士、解散与清算。

## 内容依据与整理方法

本项目主要结合以下材料进行结构化整理：

- 现行有效的中国法律、行政法规和监管规则；
- 中国证券投资基金业协会发布的自律规则、登记备案指引及合同指引；
- 已公开且已明确生效时间的规则更新；
- 有限合伙制私募基金协议的常见结构和审阅问题。

网页以“规则—分歧—起草”作为基本整理框架，并尽量通过公开规则原文进行交叉核对。

**网页当前内容更新基准日：2026 年 7 月 31 日。**

法规、自律规则、协会系统口径和地方登记政策可能继续变化，使用时仍应核验最新规定。

## 谁适合使用

- 刚接触私募股权、创业投资基金业务的法律从业者；
- 希望建立 LPA 整体框架的基金从业人员；
- 需要梳理条款审阅清单的律师、法务或投资人员；
- 希望了解法律知识如何被结构化为交互式产品的 AI 法律方向学习者。

## 本地查看

例如，在仓库目录中运行：

```bash
python -m http.server 8000
```

```text
http://localhost:8000/
```

直接使用 GitHub Pages 在线地址时，无需执行上述步骤。

## 重要提示

本项目属于 LPA 学习、审阅与起草辅助材料，不构成针对任何具体基金、交易或争议的法律意见，也不能替代对完整交易文件和具体事实的专业审查。

不同基金的组织形式、投资策略、出资人结构、监管属性、商业安排和属地登记口径可能存在显著差异。正式签署或使用相关条款前，应由具备相应经验的专业人士结合最新规则及完整材料进行复核。
